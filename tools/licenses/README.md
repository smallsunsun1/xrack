# Upstream license files

These files cover dependencies of the compiler and native preview host whose crates.io packages omit the license text.

- [fluent-langneg 0.13.1](https://github.com/projectfluent/fluent-langneg-rs/blob/7fdc590466ea63ca2367ac10fb1b881fe561f1a8/LICENSE-MIT)
- [intl_pluralrules 7.0.2](https://github.com/zbraniecki/pluralrules/blob/d0715d5b7cca72e228d6e6c4de154bd30dfdd06a/intl_pluralrules/LICENSE-MIT)

The objc2 repository [identifies MIT as an available license for its crates](https://github.com/madsmtm/objc2/blob/7b1abfd750a2cacaea71d6a56ecfb83cb7de560b/LICENSE.md). The package includes the MIT text and the original Cargo manifest for each affected crate. The SPIR-V and profiling crates supply an Apache-2.0 option and use the repository's standard Apache text alongside their original manifests.
